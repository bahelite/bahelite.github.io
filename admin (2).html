প্রথমবার সংযুক্ত করুন

GitHub থেকে একটি "টোকেন" বানিয়ে এখানে বসাতে হবে। এটি শুধু একবারই লাগবে, আর শুধু আপনার ফোনে থাকবে।

  1. github.com → ছবি → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. নাম: bah-admin। Expiration: ১ বছর
  4. Repository access: Only select repositories → bahelite.github.io
  5. Permissions → Repository permissions → Contents: Read and write
  6. Generate token চেপে টোকেনটি কপি করুন
